# Required Skill Logos

You need to download and add the following logo images to the `assets/images/skills/` folder:

## New Skills Logos Needed:

1. **c.png** - C programming language logo
   - Download from: https://cdn.jsdelivr.net/gh/devicons/devicon/icons/c/c-original.svg
   - Convert to PNG (24x24 or 48x48 pixels)

2. **docker.png** - Docker logo
   - Download from: https://cdn.jsdelivr.net/gh/devicons/devicon/icons/docker/docker-original.svg
   - Convert to PNG (24x24 or 48x48 pixels)

3. **js.png** - JavaScript logo
   - Download from: https://cdn.jsdelivr.net/gh/devicons/devicon/icons/javascript/javascript-original.svg
   - Convert to PNG (24x24 or 48x48 pixels)

4. **kotlin.png** - Kotlin logo
   - Download from: https://cdn.jsdelivr.net/gh/devicons/devicon/icons/kotlin/kotlin-original.svg
   - Convert to PNG (24x24 or 48x48 pixels)

5. **mysql.png** - MySQL logo
   - Download from: https://cdn.jsdelivr.net/gh/devicons/devicon/icons/mysql/mysql-original.svg
   - Convert to PNG (24x24 or 48x48 pixels)

6. **php.png** - PHP logo
   - Download from: https://cdn.jsdelivr.net/gh/devicons/devicon/icons/php/php-original.svg
   - Convert to PNG (24x24 or 48x48 pixels)

7. **selenium.png** - Selenium logo
   - Download from: https://cdn.jsdelivr.net/gh/devicons/devicon/icons/selenium/selenium-original.svg
   - Convert to PNG (24x24 or 48x48 pixels)

## Alternative Sources:
- Simple Icons: https://simpleicons.org/
- Devicon: https://devicon.dev/
- Icon Scout: https://iconscout.com/

## How to Add:
1. Download each logo
2. Resize to approximately 24x24 or 48x48 pixels (PNG format)
3. Save with the exact filename listed above
4. Place in: `assets/images/skills/`

## After Adding Images:
Run `flutter pub get` to refresh the asset bundle.
